# 과제 07: 인접 행렬과 인접 리스트의 성능 비교 보고서

## 1. 개요
본 과제는 정점(Vertex) 100개로 구성된 무방향 단순 그래프를 대상으로, 희소 그래프(Sparse Graph, 간선 100개)와 밀집 그래프(Dense Graph, 간선 4,000개) 환경에서 인접 행렬(Adjacency Matrix)과 인접 리스트(Adjacency List)의 표현 방식에 따른 메모리 사용량 및 주요 연산의 비교 횟수 성능을 측정한 실증 보고서입니다.

---

## 2. 측정 데이터 요약 및 비교 표

| 구분 | Case 1: 희소 - 행렬 | Case 2: 희소 - 리스트 | Case 3: 밀집 - 행렬 | Case 4: 밀집 - 리스트 |
| :--- | :---: | :---: | :---: | :---: |
| 메모리 사용량 (Memory) | 40,008 Bytes | 4,008 Bytes | 40,008 Bytes | 128,808 Bytes |
| 간선 삽입 비교 (Insertion) | 1 | 2 | 1 | 81 |
| 간선 삭제 비교 (Deletion) | 1 | 5 | 1 | 84 |
| 연결 여부 확인 (Connectivity) | 1 | 4 | 1 | 53 |
| 인접 정점 출력 (Adjacent) | 100 | 5 | 100 | 74 |

---

## 3. 실증 데이터를 바탕으로 한 심층 분석

### 1) 메모리 공간 효율성 분석
- 희소 그래프 (Sparse Graph): 인접 행렬은 간선 수와 무관하게 고정 크기의 2차원 배열을 할당하여 40,008 Bytes를 소모하는 반면, 인접 리스트는 4,008 Bytes만 사용하여 약 1/10 수준의 메모리 절감 효과를 보여줍니다.
- 밀집 그래프 (Dense Graph): 간선이 4,000개로 증가함에 따라 인접 리스트는 동적 노드 오버헤드(포인터 및 데이터)가 급증하여 메모리 사용량이 128,808 Bytes로 크게 늘어납니다. 즉, 간선 밀도가 높아지면 인접 리스트가 인접 행렬(40,008 Bytes)보다 약 3.2배 더 많은 메모리를 사용합니다.

### 2) 연산 성능(비교 횟수) 분석
- 단일 간선 연산 (삽입 / 삭제 / 연결 확인):
  - 인접 행렬: 인덱스를 통해 직접 접근($O(1)$)하므로 그래프 밀도와 무관하게 항상 단 1회의 비교만 수행합니다.
  - 인접 리스트: 연결 리스트를 순회하므로 희소 그래프에서는 2~5회로 적으나, 밀집 그래프에서는 차수가 커짐에 따라 비교 횟수가 53~84회로 대폭 증가합니다.
- 특정 정점의 모든 인접 정점 출력:
  - 인접 행렬: 0번부터 99번 정점까지 행 전체를 조회하므로 밀도와 상관없이 항상 100회의 비교가 발생합니다.
  - 인접 리스트: 실제 연결된 노드만 순회하므로 희소 그래프에서는 5회, 밀집 그래프에서도 실제 연결된 차수 수준인 74회만 비교하여 두 경우 모두 인접 행렬보다 인접 정점 탐색이 빠릅니다.

---

## 4. 결론 및 결론적 가이드라인
1. 희소 그래프 (Sparse Graph) 환경에서는 메모리를 90% 이상 절약하고 탐색 효율도 우수한 인접 리스트가 절대적으로 적절합니다.
2. 밀집 그래프 (Dense Graph) 환경에서는 간선 증가로 인한 포인터 오버헤드로 리스트가 더 많은 메모리를 소모하며, $O(1)$로 즉시 접근할 수 있는 인접 행렬이 공간 및 연산 속도 측면에서 모두 훨씬 우수합니다.
